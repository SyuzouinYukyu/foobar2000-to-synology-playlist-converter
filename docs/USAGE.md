# 使い方

## 1. 事前準備

プレイリスト変換前に、次の3点を確認してください。

1. foobar2000 側でプレイリストを `.m3u` または `.m3u8` として保存していること
2. Windows から音源ファイルの実体にアクセスできること
3. Synology NAS 側で使用する音源ルートが決まっていること

## 2. 基準パスの考え方

このツールでは、Windows側のローカル/ドライブパスを、NAS側で通用する基準パスへ置換します。

例:

| 項目 | 例 |
|---|---|
| Windows側の音源ルート | `G:\AMZN_01` |
| NAS側の基準パス | `/volume1/AMZN_01` |
| 変換前の曲パス | `G:\AMZN_01\Artist\Album\track01.flac` |
| 変換後の曲パス | `/volume1/AMZN_01/Artist/Album/track01.flac` |

## 3. 推奨運用

最初から巨大なプレイリストを投入せず、まずは10曲程度のテスト用プレイリストで動作確認してください。

確認すべき点:

- 文字化けしていないか
- 曲順が維持されているか
- NAS側でパスが解決できるか
- 区切り文字が想定通りか
- 存在しないファイルが大量に出ていないか

## 4. NAS基準の入力例

Synology の共有フォルダやメディアサーバー構成により、適切な値は変わります。

代表例:

```text
/volume1/music
/volume1/AMZN_01
/volume1/AMZN_02
```

DLNA / UPnP アプリ側で別の仮想パスを要求する場合は、そのアプリが参照する形式に合わせてください。

## 5. ログ保存

変換時にログが出力される場合は、ログを保管しておくと再現調査に役立ちます。

公開Issueへ貼る場合は、次の情報を伏せてください。

- Windowsユーザー名
- 非公開フォルダ名
- NASの内部構成
- 個人名・作品管理上の秘匿情報

## 6. 失敗しやすい例

### Windows側の基準パスが深すぎる

`G:\AMZN_01\Artist` のように途中階層を基準にすると、想定外の変換になる場合があります。通常は音源ライブラリの最上位に近い位置を指定します。

### NAS基準が空欄または誤っている

NAS側で認識される実パス、または利用アプリが期待するパス形式を入力してください。

### 文字コード混在

古い `.m3u` は Shift_JIS / CP932、`.m3u8` は UTF-8 系で保存されている場合があります。文字化けが出る場合は、プレイリストの保存形式を確認してください。
