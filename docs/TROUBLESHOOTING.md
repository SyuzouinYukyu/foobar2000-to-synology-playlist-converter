# トラブルシューティング

## Windows SmartScreen が警告する

EXEがコード署名されていない場合、Windows SmartScreen が警告を表示することがあります。

対処:

1. ファイルの入手元が正しいことを確認
2. SHA-256 を確認
3. セキュリティソフトでスキャン
4. 問題ないと判断できる場合のみ実行

## 変換後のプレイリストをNASで読めない

次を確認してください。

- NAS基準パスが Synology 側の実態に合っているか
- 区切り文字 `/` と `\` の扱いが再生アプリの期待通りか
- 音源ファイルの配置場所がNAS上で一致しているか
- 変換対象の拡張子を再生アプリがサポートしているか

## 文字化けする

`.m3u` / `.m3u8` の文字コードを確認してください。

一般的には、可能であれば UTF-8 BOM 付きまたは UTF-8 の `.m3u8` を推奨します。

## 曲が見つからない

Windows側のプレイリストに記録されたパスが、現在の実ファイル配置と一致しているか確認してください。

特に、ドライブレター変更、NASマウント変更、フォルダ名変更後は不一致が発生しやすくなります。

## GitHub へEXEを置けない

100MiBを超えるファイルは通常の GitHub リポジトリへ直接 push できません。

推奨:

- EXEは GitHub Releases の Assets にアップロード
- リポジトリには README、ハッシュ、手順書のみ配置
- どうしてもリポジトリ管理したい場合は Git LFS を使用
